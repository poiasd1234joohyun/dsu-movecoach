# media 폴더 — 팀이 직접 찍은 사진·영상을 넣는 자리

파일을 아래 이름으로 넣으면 화면에 자동으로 나타납니다. 없으면 가상 인물 그림만 보입니다.

| 파일 이름 | 어디에 보이나 | 무엇을 찍나 |
|---|---|---|
| `tutorial1.mp4` ~ `tutorial6.mp4` | "사용법" 화면 맨 위와 첫 화면의 "사용법 영상" | 사용법 설명 영상 |
| `guide.mp4` | 첫 화면 오른쪽 안내 자리(움직이는 그림 대신) | 실제 사용 장면 30~60초 |
| `scene_squat.mp4` 또는 `.jpg` (`scene_match`, `scene_bow`, `scene_run`, `scene_cpr`, `scene_plank`, `scene_race`) | "이런 동작에 씁니다"에서 그 장면을 눌렀을 때 그림 아래 | 실제 수업 장면 |

## 사용법 영상에 제목을 붙이거나 유튜브 영상을 쓰려면

`tutorials.json` 을 아래처럼 고칩니다. `src` 에는 이 폴더의 파일 이름이나 유튜브 주소를 적습니다. 이 파일에 하나라도 적으면 `tutorial1.mp4` 같은 이름 규칙 대신 이 목록을 씁니다.

```json
[
  {"title": "모범 영상 올리기", "desc": "찍어 둔 영상을 올려 모범으로 만드는 법", "src": "tutorial1.mp4"},
  {"title": "학생이 따라 하는 모습", "src": "https://youtu.be/영상주소"}
]
```

## 지킬 것

- **팀원 본인**이 나온 것만 넣습니다. 학생이 나온 사진·영상, 인터넷에서 받은 남의 영상은 넣지 않습니다(대회 규정: 가상 데이터만).
- GitHub 웹 화면으로는 파일 하나에 25MB까지만 올라갑니다. 폰 영상은 길면 훨씬 크므로, 긴 영상은 유튜브(일부 공개)에 올리고 주소를 `tutorials.json` 에 적는 편이 쉽습니다.
