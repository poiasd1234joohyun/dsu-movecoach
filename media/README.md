# media 폴더 — 팀이 직접 찍은 사진·영상을 넣는 자리

파일을 아래 이름으로 넣으면 화면에 자동으로 나타납니다. 없으면 가상 인물 그림만 보입니다.

| 파일 이름 | 어디에 보이나 | 무엇을 찍나 |
|---|---|---|
| `guide.mp4` | 첫 화면의 사용법 안내 자리(움직이는 그림 대신) | 실제 사용 장면 30~60초 |
| `sample_squat.mp4` | 1분 체험 → "찍어 둔 영상" 버튼 | 팀원 본인의 전신 스쿼트 약 20초(옆에서) |
| `scene_squat.mp4` 또는 `.jpg` | "이런 수업에" → 스쿼트 장면 아래 | 실제 수업 장면 |
| `scene_match.*`, `scene_bow.*`, `scene_run.*`, `scene_cpr.*`, `scene_plank.*`, `scene_race.*` | 각 장면 아래 | 양궁·인사·달리기·가슴압박·플랭크·게임 장면 |

지킬 것
- **팀원 본인**이 나온 것만 넣습니다. 학생이 나온 사진·영상, 인터넷에서 받은 남의 영상은 넣지 않습니다(대회 규정: 가상 데이터만).
- mp4는 10MB 이하로 줄여서 넣습니다(폰에서 빨리 열리게).
