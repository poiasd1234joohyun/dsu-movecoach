# DSU 무브코치

**모범 동작 영상을 올리면, 학생들이 따라 하며 배운다.**
2026 DSU AI 챌린지 B트랙(교원·개발형) 출품작입니다.

- 만드는 사람(교수·조장 누구나): 폰으로 찍어 둔 **모범 영상을 올립니다**(멈춘 자세는 사진도 됨). AI가 영상 속 동작을 읽어 모범으로 등록합니다. 같은 동작을 여러 번 한 영상이면 그 평균을 씁니다. 방식(연습 / 과제·시험 / 게임)을 고르면 링크와 QR이 나옵니다.
- 참여하는 사람: 링크를 폰으로 열어 모범 동작을 먼저 보고, 2~3m 뒤에서 따라 합니다. **모범과 맞을 때만 횟수가 올라가고**, 다른 곳은 그 자리에서 말로 알려 줍니다. 끝나면 몇 번 맞았는지와 어느 부위가 어느 구간에서 달랐는지를 받습니다.
- 결과: 기록 서버가 있는 주소에서는 만든 사람의 관리 링크에 저절로 모입니다. 없는 주소(GitHub Pages)에서는 참여자가 "결과 보내기"로 링크를 보내면 만든 사람의 기기 목록에 들어갑니다.
- 준비된 동작(스쿼트·푸시업·런지·인사·달리기·플랭크·가슴압박·심폐소생술 절차)도 고를 수 있습니다.
- 회원가입·앱 설치가 없습니다. 영상은 올린 사람의 기기 안에서만 읽고, **외부 AI(유료 API)를 부르지 않습니다.**

## 폴더 구성

```
index.html      ← 화면 완성본. 이 파일 + vendor/ + media/ 가 화면의 전부다
version.txt     ← 빌드 번호(build.py 가 씀). 브라우저에 예전 화면이 남아 있으면 이 번호를 보고 저절로 새로 고친다
server.js       ← 작은 웹 서버 + 기록 서버(/api). 여러 기기의 기록을 한곳에 모은다
vendor/         ← 자세 인식 실행 파일(MediaPipe), QR 부품 (vendor/README.md 에 출처·라이선스)
media/          ← 팀이 직접 찍은 사진·영상 자리 (media/README.md 에 파일 이름 규칙)
src/            ← 원본 조각. 고칠 때는 여기를 고치고 build.py 를 돌린다
  v4_head.html  화면 뼈대와 디자인
  engine.mjs    분석 엔진: 관절 좌표 → 각도 → 판정. 반복·유지·속도·절차·달리기·멈춘 모범 자세, 그리고 모범 동작(3번 평균 만들기, 시간축 맞춰 따라 하기 채점, 한 손 들기 신호)
  synth.mjs     가상 인물(계산으로 만든 관절 좌표): 그림, 카메라 없는 시연, 샘플 기록, 자동 점검에 쓴다
  v4_core.js    공통: 저장, 기록 서버 연결, 음성·효과음, 카메라, 한 세션의 시작~결과
  v5_visual.js  그림: 가상 인물 그리기, 아이콘, 동작별 교정 전·후 장면, 모범 동작 재생, 첫 화면의 사용법 안내(음성 설명)
  v6_game.js    게임 그림: 직접 그린 캐릭터 8종, 경주 트랙, 색종이
  v5_match.js   모범 만들기: 영상 올리기(읽기 → 구간 확인 → 등록) / 사진(멈춘 자세) / 이 기기의 카메라로 찍기(한 손 신호로 3번)
  v4_app1.js    첫 화면, 활용 분야, 사용법 영상, 링크 만들기(모범 → 방식 → 링크, 내가 올린 모범 보관함), 내 링크
  v4_try.js     구경하기(가상 인물 시연), 샘플 수업방(가상 학생 24명), 기기 점검
  v4_app2.js    참여 화면, 시험, 관리 화면·순위판, 게임, 주소 처리
tests/          ← 자동 점검 4종
tools/          ← 모델 파일 받는 스크립트
legacy/         ← 예전 방식(구글 스프레드시트)의 기록 서버. 지금은 쓰지 않는다
```

## 고치고 점검하는 법

```bash
python3 build.py                      # src/ 조각을 합쳐 index.html 다시 만들기
node --check build/main.mjs           # 문법 검사
node tests/test_engine.mjs            # 분석 엔진 110항목 (끝에 ALL OK)
node tests/test_api.mjs               # 기록 서버 (끝에 ALL OK). TEST_PG_URL 을 주면 PostgreSQL 도 점검
cd tests && node test_ui.mjs          # 화면 전체 흐름, 기록 서버 없는 상태 (끝에 errors: [])
node tests/test_server.mjs            # 서버로 띄우고 여러 기기로 접속, 바깥 인터넷 차단 (끝에 ALL OK)
```

소스를 고치면 `v4_core.js` 의 `BUILD` 숫자를 하나 올리고, `build.py` → 점검 4종 순서로 확인합니다. 올릴 때는 `index.html` 과 `version.txt` 를 함께 올립니다.

## 인터넷 주소에 올리는 법

올리는 곳에 따라 되는 일이 다릅니다.

| 올리는 곳 | 화면 | 여러 사람의 기록이 한곳에 모임 |
|---|---|---|
| GitHub Pages (파일만 올라감) | 됨 | **저절로는 안 됨** — 참여자가 "결과 보내기" 링크를 보내야 한다. 모범이 링크 안에 담겨 주소가 길다(약 1,500자). 참여자에게는 실제 영상이 아니라 읽어 낸 인물 그림이 보인다 |
| `server.js` 가 도는 곳 (학교 배포 서비스 등) | 됨 | **됨** — 짧은 링크, 관리 화면, 실시간 순위판, 조별 기록, 올린 모범 영상(20MB 이하)을 참여자에게 그대로 보여 주기 |

1. **GitHub Pages**: 저장소 Settings → Pages → Branch `main`, 폴더 `/ (root)` → Save.
2. **서버가 도는 곳**: `npm install` 뒤 `node server.js`. 환경 변수 `PORT`(기본 8000)에서 `0.0.0.0` 으로 열립니다. `Dockerfile` 도 들어 있습니다.
   - 환경 변수 `DATABASE_URL` 이 있으면 PostgreSQL 에 저장합니다. 없으면 `data/` 폴더의 파일에 저장합니다(서버를 새로 올리면 지워질 수 있음).
   - 화면은 같은 주소의 `/api` 를 자동으로 찾아 씁니다. 따로 설정할 것이 없습니다.
3. 내 컴퓨터에서 보기: `node server.js` → `http://localhost:8000`

올린 뒤에는 주소 끝에 `#check` 를 붙여 **기기 점검** 화면에서 폰·노트북마다 되는지 확인합니다.

## 지키는 것

- 실제 학생·교직원 데이터를 쓰지 않습니다. 샘플 수업방의 학생과 화면의 그림은 모두 가상 인물이며, 점수는 분석 엔진이 가상 동작을 채점한 결과입니다.
- 열쇠(API 키)나 비밀번호, 참여자 기록(`data/`)을 저장소에 올리지 않습니다.
- 카메라 영상은 참여자가 과제·시험에서 직접 "제출"할 때만 기기 밖으로 나갑니다. 모범은 사진·영상이 아니라 숫자(시간에 따른 관절 각도와 윤곽 좌표, 약 1KB)로만 저장하고, 참여자에게는 그 움직임을 옮긴 인물 그림으로 보여 줍니다.
- 캐릭터·아이콘·인물 그림은 모두 이 프로그램 안에서 선과 면으로 직접 그립니다(그림 파일, 다른 작품의 캐릭터 없음).

## 정확도에 대해

폰 카메라 한 대로 화면 속 관절 위치를 추정합니다. 몸에 센서를 붙이는 측정 장비처럼 정밀하지 않고, 화면에 보이지 않는 것(힘, 깊이, 손가락 모양)은 재지 못합니다. 수업·연습용 교정 도구이며, 정밀 측정 장비가 아닙니다.
모범 동작의 판정 기준(보통: 허용 범위 ±18°, "맞음" 75%)과 영상에서 동작 구간을 찾는 규칙은 가상 동작으로만 맞춘 값입니다. 실제 촬영으로 더 맞춰야 합니다.
얼굴 표정(미소), 손가락, 붕대처럼 물체의 모양은 지금 쓰는 인식기(몸의 관절 33곳)로 볼 수 없습니다(활용 분야 화면의 "발전 과제").
"달리기 자세"는 시범 단계 동작으로, 기준값을 실제 영상으로 더 맞춰야 합니다.

## 쓰는 기술

- 자세 인식: Google MediaPipe Pose Landmarker(관절 33개), 브라우저 안에서 실행 (Apache-2.0)

- 음성·효과음·녹화: 브라우저 기본 기능 / QR: QRCode.js (MIT) / 저장: PostgreSQL 또는 파일(`pg`, MIT) / 글꼴: Pretendard(OFL), 못 받으면 Noto Sans KR·기기 글꼴
